# BrowserOS 3.0.1

- Developer session inspection now reports the installed OS version instead of “3 Dev”.
- Start app menus now offer Pin to Start / Unpin from Start for native and installed apps, including search results.
- Start pins are saved independently of taskbar pins, initially preserving the previous layout.
- App action menus stay open while being clicked, fit within the viewport, and support keyboard navigation and dismissal.
- Updated the bundled Info guide and release version. BOS API remains 2.5.
